# 小红书私信引流

使用用户已登录的 Codex 右侧边栏 `iab`。先处理私信，再检查账号全部可达招聘笔记的评论。用户要求执行且明确给定话术、运营负责人及提醒群时，授权覆盖这些回复、任务和群提醒；技能文件本身不授予其他账号或其他收件人的操作权限。

## 运行输入与记录

- 从本次任务或本机私有配置读取小红书账号主页、运营负责人 open_id、提醒群 chat_id、共享状态目录。核对当前账号与负责人，不能仅凭同名匹配。
- 读取上轮回执和断点；执行进度写入私有状态目录。候选人联系方式、截图、群 ID、凭据不进入 Skill、公开仓库或公共报告。
- 主 Agent 独占浏览器。发现联系方式后立即委派飞书子 Agent，主流程继续浏览器。子 Agent 只收到本批明确来源、岗位及原文，不控制浏览器。结束前收齐并核对回执。
- 无子 Agent 能力时可串行交接，必须明确降级；不可把排队当创建成功。

## 1. 私信

浏览器细节见 [references/browser.md](references/browser.md)。读取主会话列表及“陌生人消息”，逐项判断，滚动到可达末尾并记录覆盖范围。未读红点只是导航提示；点开即消失，不代表已回复或已交接。

| 观察到的状态 | 动作 |
|---|---|
| 明确咨询招聘岗位或投递、我方尚未回复 | 发送下方固定私信原文 |
| 发来本账号招聘笔记或岗位评论并求对接 | 核对招聘内容后同上 |
| 我方已索取联系方式，尚无新联系方式 | 不重复索取 |
| 对方回复联系方式，尚无有效交接回执 | 提交飞书子 Agent 去重和创建任务 |
| 最新是我方正常答复、普通感谢、闲聊 | 跳过重复回复 |
| 已是微信好友、催促未收到添加、课程、企业招聘或合作、含糊岗位问题 | 摘要转指定群；已有联系方式可交接，准确标注性质 |

私信原文（不得自行改写）：

> 可以发我一下您的 lian 系 fang 式嘛，我小红书消息太多了，我来➕您对接一下。

先读完整上下文，再决定是否适用。岗位名称取真实笔记/会话内容；候选人猜测的公司名不当作事实。发送后必须看到本人消息和相符文本，不能仅凭 Enter、输入框清空或未读消失判断成功。

## 2. 飞书并行交接

详细命令与去重见 [references/lark.md](references/lark.md)。通过 `lark-cli` 创建运营同事负责的逐人任务，要求用其自己的号添加并对接。负责人必须实际写入 assignee。

任务包含：小红书昵称与稳定用户 ID、会话 URL、岗位/需求、联系方式原文、类型是否确定、必要上下文、下一步和完成标准。完整微信号保留大小写、下划线与连字符；手机号只在原文分组明确时去空格。手机号未明说微信同号时不能推断；`wxid_`、二维码或模糊截图标记人工核实，不猜搜索账号。清晰图片需放大阅读。

同时按完整联系方式与来源用户 ID 查历史任务（包括已完成）。命中后回读具体正文，不能仅靠搜索命中标题或任意子串去重。旧任务完成但对方新追问时提醒团队跟进，不重新发同一加好友任务。提交超时先回读再重试。新任务回读负责人、正文及 GUID 后才记成功；创建任务不等于已添加好友。

特殊情况按批次合并群消息，仅必要摘要和来源/任务链接；无须把每位候选人的联系方式广播到群里。同一异常不重复通知。

## 3. 招聘笔记评论

主页分页枚举笔记并按 note ID 去重；保存实际 href 中的访问参数。先判断笔记是否招聘内容，非招聘内容不套用招聘话术。招聘笔记逐篇检查评论，滚动到 `- THE END -` 或明确空评论，展开折叠回复，检查子评论中新追问。

仅对有求职/岗位咨询意向、未得到作者回复的评论，点击该条“回复”，核对回复对象和原文，再发送：

> 可以 si 我一下，我来对接！

已有作者“私”“可以聊聊”等回复时跳过。其他网友回复不算作者已答。普通点赞、同行广告、课程讨论、无意向感想不套话术。同一用户同一笔记重复举手，一次引导即可。对已回复后的独立岗位追问可以回复新评论。

发送后回读对应父评论或子线程内的作者回复，保存 note ID、comment ID、原文、结果；仅有评论总数增加不算对象核验。分页或折叠未完成时明确剩余范围，不能宣称全量检查。

## 4. 收尾和定时运行

汇总实际核验的私信数、评论数、飞书任务数、去重数和特殊提醒。保留失败/不确定记录，供下轮先回读再恢复。停止本轮专属防休眠进程，保留用户标签页及业务记录。

定时任务使用平台 automation 工具；默认复用同一聊天的 heartbeat，不创建外部系统 cron。若要求北京时间每天08:30和20:00，建两个精确时点，不能用12小时间隔或小时/分钟笛卡尔组合。启用前核对重复任务，创建后回读时点、时区、启用状态和 Skill 路径。机器/应用及登录态不可用、验证码或平台限制时保留断点并报告，不绕过验证或改账号。仅在有新处理结果、异常、失败或需要用户行动时通知；无变化保持安静。
