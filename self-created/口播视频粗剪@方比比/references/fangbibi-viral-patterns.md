# 方比比爆款选段判断框架

本参考来自方比比飞书案例库中“原素材文案 → 最终爆款文案 → 爆款原因分析”的提炼。执行时用它做判断框架，不要把案例标题原样套到新视频。

## 基本成片结构

方比比口播爆款常见结构是：

```text
采访问题开头 → IP用一句话回答 → 具体故事或行为细节 → 情绪/认知反转 → 金句收尾
```

开头问题很重要。它不是单纯提问，而是让观众同步进入思考：

- “你觉得妈妈最大的优点是什么？”
- “你挣了这么多钱，都花哪了？”
- “你年入百万，买衣服均价多少钱？”

问题越具体，越能让观众下意识代入。

## 结构类型

### 1. 极简金句提纯

适合素材中有一条极短但杀伤力很强的句子。

判断标准：

- 句子不需要复杂上下文也能成立。
- 听完后现场或观众会安静一下。
- 适合保留提问后的停顿，让回答显得像认真思考，而不是背台词。

剪辑动作：

- 删除所有 NG、笑场、试语气、导演指导和自我评价。
- 只保留开头问题、自然停顿、最终金句、短余韵。
- 可以只有 6-15 秒，不必强行拉长。
- 成片文案必须从原素材逐字截取，不要把金句润色得更顺。

### 2. 节俭破例 + 口是心非 + 角色反转

适合“给父母/妈妈做了一件具体的好事”的素材。

判断标准：

- 先建立平时节俭、舍不得、克制的人设。
- 再出现一个为妈妈破例的具体行动。
- 父母有“嘴上不要、心里得意”的行为佐证。
- 结尾能升维到“以前妈妈养我，现在我把妈妈当孩子养”一类角色反转。

剪辑动作：

- 保留“平时省”和“这次破例”的反差。
- 保留父母反应里的可爱细节，如发朋友圈、嘴上拒绝、偷偷开心。
- 删除具体金额堆砌，除非数字本身就是钩子。
- 把角色反转金句放最后。
- 输出报告时要把删掉的金额讨论、NG 或解释性绕路用删除线列出来。

### 3. 反常识事实 + 价值观翻转 + 极端案例 + 规律金句

适合“年入百万但消费/生活方式反常识”的素材。

判断标准：

- 有清楚财富锚定或身份锚定。
- 有一个具体反常识事实，例如“衣服只买 300 元”。
- 有一句解释把负面行为翻成正面价值观，例如“不买贵衣服不是抠，是买衣服太花时间”。
- 有一个极端案例佐证价值观。
- 结尾能提炼成对称、易记、可转发的规律金句。

剪辑动作：

- 先放财富锚定，再放反常识事实，冲击力最大。
- 反常识之后马上给翻转解释。
- 用人物故事增强可信度。
- 最后用规律金句压轴。
- 如果原话口语、不完整但可剪，优先保留原话；不要补成更漂亮的书面句。

### 4. 杀爱原则

原素材里常常有很多“也不错”的内容，例如家庭背景、性格剖析、知识付费、创业经历。只要不服务本条视频的核心主题，就删除。

一条视频只服务一个核弹。宁可删除深刻但偏题的内容，也不要让视频变成“什么都讲一点”。但删除必须透明：报告要展示删掉了哪些原句，而不是只给剪完后的版本。

## 刺点类型

### 钩子刺点

负责让观众停留，通常来自：

- 反常识：年入百万却只买 300 元衣服。
- 提问代入：你妈妈最大的优点是什么？
- 冲突：这么有钱为什么不花？
- 自嘲：我都攒着，一分钱没花。

### 爱心刺点

负责让观众认同、心疼、会心一笑：

- 妈妈把所有时间都给了家。
- 父母表面说不用，其实心里可得意。
- 自己第一次坐商务座，却先带妈妈坐。
- 同款衣服买几件，因为不想把精力浪费在选择上。

### 转发刺点

负责让观众拿这条视频表达自己：

- 妈妈的存在就是最好的优点。
- 以前妈妈把我当孩子，现在我想把妈妈当孩子重新养一遍。
- 极致的专注，才能有极致的结果。

### 评论刺点

负责引发观众说“我也是”“我妈也是”“这孩子懂事”：

- 中国父母的口是心非。
- 子女想反哺父母但又怕父母拒绝。
- 年轻人赚到钱后的消费观。
- 妈妈/孩子之间未说出口的亏欠和骄傲。

## 选段 Checklist

推荐片段前逐项检查：

- 是否能用一个问题开头？
- 是否有明确的主题，不混多个主题？
- 是否有具体行为、数字、对话或画面？
- 是否有情绪或认知反转？
- 是否有可压轴的短金句？
- 是否删掉了 NG、导演引导、制作过程和旁支故事？
- 是否听起来像真实回答，而不是脚本朗读？
- 是否能让观众产生爱心、转发或评论动机？
