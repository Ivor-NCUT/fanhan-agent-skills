# 理白风格写作

一个用于复用「理白」公众号内容风格的 Agent Skill。

## 适用场景

- 诊断一篇稿子是否符合理白风格
- 把已有稿件润色成理白公众号风格
- 根据主题、素材、访谈或业务现场创作公众号文章
- 优化标题、开头、结尾和转化段

## 风格重点

这个 skill 不做表面口癖模仿。它优先复刻：

- 真实业务现场
- 强判断
- 商业解释
- 可迁移规则
- 边界和筛选
- 服务、口碑、承接和长期复利

## 文件结构

- `SKILL.md`：skill 入口和高频写作流程
- `references/source-style-overview.md`：完整风格概述
- `references/source-samples.md`：样本索引
- `evals/evals.json`：基础测试提示

## 边界

- 不编造作者经历、客户案例、业务数据、截图和公众号历史
- 不洗稿
- 用户事实优先，风格规则其次
- 素材不足以支撑强势判断时，降低语气或标注待补事实
