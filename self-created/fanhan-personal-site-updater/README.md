# 泛函个人网站内容更新

这是给泛函本人使用的个人网站更新 Skill。你只需要告诉 Codex 想改哪个栏目并提供真实资料，Codex 会按网站现有卡片样式整理内容、修改页面并完成检查。

## 可以更新什么

1. 候选人代表
2. 泛函的朋友们
3. 内容与课程
4. 精选活动
5. 有意思的社区或俱乐部
6. 精选影视艺术
7. 精选书籍

公司和岗位不由这个 Skill 维护，仍由百纯负责。

## 最简单的使用方法

在 Codex 中输入：

```text
使用 $fanhan-personal-site-updater 更新我的个人网站。
```

Codex 会先让你选择栏目。你也可以直接说清楚栏目和动作，例如：

```text
使用 $fanhan-personal-site-updater，在“精选书籍”新增《书名》，作者是……，我的推荐理由是……，链接是……。先给我预览。
```

```text
使用 $fanhan-personal-site-updater，把“泛函的朋友们”里某人的简介改成以下内容并上线：……
```

## 你需要提供什么

最少提供名称或标题，以及一段真实简介或推荐理由。链接、图片、标签、时间、作者等资料可直接用自然语言一起发给 Codex，不需要自己整理成表格。缺少必填信息时，Codex 会一次性问完。

## “预览”和“上线”的区别

- 说“先看看、预览、草稿”：只生成本地预览，不发布。
- 说“更新、添加、修改到网站、上线、发布”：完成测试后同步 GitHub 并部署网站。

## 使用边界

- 不编造人物经历、推荐理由、数据、链接或合作关系。
- 图片只使用你提供、仓库已有或确认可公开使用的素材。
- 删除或替换现有内容时，需要明确说出目标和动作。
- 微信、二维码等联系方式只有在你明确要求公开时才会发布。
