# 工作流沉淀

本 skill 来自一次真实任务：

1. 用户提供一份飞书录音转写稿和一份飞书 Slides 课件。
2. 先读取转写稿，解析 wiki Slides 的真实 `obj_token`。
3. 先将 Slides 导出为 PDF，再用 `pdftoppm` 转成 42 张 PNG。
4. 将转写稿整理成课程文档初稿。
5. 用 `docs +media-insert` 将图片逐页插到对应段落。
6. 将“说明书式教程”改成“主讲人现场授课口吻”的课程稿。
7. 删除所有“课件页XX：...”机械标识。
8. 用逻辑延续标准检查全文，补过渡、压空转、调顺章节。

关键经验：

- 飞书 Slides 导出为 PDF 再转图，比直接用 Keynote 导出逐页图片稳定。
- 图片插入飞书后，后续整篇 Markdown 覆盖可以保留图片引用，但每次覆盖后都要复核图片数量。
- 图文课程稿不要保留“课件页01”标识；图片本身已经承担课件定位。
- 课程稿的开头要说明“本课任务”，不要写成泛泛介绍。
- 逻辑延续优化主要补章节之间的一句话，不要大改观点。
