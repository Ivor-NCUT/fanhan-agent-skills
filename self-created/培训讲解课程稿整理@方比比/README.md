# 培训讲解课程稿整理@方比比

把线下培训或团队讲课的「PPT/课件 + 录音转写稿」整理成一篇图文混排课程文档。

## 适用场景

- 线下培训讲完后，需要整理成飞书课程文档。
- 有 PPT 和录音转写稿，希望合成图文教程。
- 内部分享、工作坊、团队培训需要变成可复盘的讲义。
- 已经有逐字稿，但文字太口语、太散，需要课程化润色。

## 核心流程

1. 读取课程转写稿。
2. 解析 PPT / 飞书 Slides / PDF。
3. 先把课件导出 PDF，再逐页转 PNG。
4. 把转写稿改写成正式课程稿。
5. 将图片插入到对应讲解部分。
6. 删除“课件页01”这类机械标识。
7. 检查逻辑延续，补过渡、压重复、调顺正文。
8. 写回飞书文档并复核。

## 常用触发语

- “这是培训录音转文字和 PPT，帮我整理成图文课程文档”
- “把这次线下课整理成飞书教程”
- “PPT 每页导出图片插到对应讲解里”
- “把讲课逐字稿润色成课程稿”
- “检查一下这篇培训稿逻辑顺不顺，顺便优化”
