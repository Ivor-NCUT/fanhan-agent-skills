# 来源与许可

- 本 Skill 的流程、文案规则和 Codex 浅色模板来自本地项目 `genius-career-advisor-promo-mvp` 的原创迭代成果。
- HyperFrames、GSAP、FFmpeg、Codex 和音乐分析能力是外部依赖；Skill 只调用，不复制其说明文档或第三方代码。
- 小红书参考视频只用于抽象动效观察，不在 Skill 中重新分发画面、音频或原始素材。
- 用户提供的 BGM 不进入公开 Skill 包。最终成片公开发布前由使用者确认音乐版权与授权范围。
- `assets/notification-chime.wav` 是本项目用基础正弦波自行合成的提示音，不含第三方采样。
- `vendor/motion-web/` 来自 [feitangyuan/motion-web](https://github.com/feitangyuan/motion-web)，固定于提交 `440316bfbb0f527c8775ff9104189d1b0db99ce9`，按 MIT License 内嵌；原作者版权与许可全文保留在 `vendor/motion-web/LICENSE`。本包不包含上游 31MB 宣传素材目录。
