# 0.2 验收用例

真实反馈：有剧本时应向使用者索取并以其为准；没有剧本时才由 Agent 自行构思，避免默认生成不稳定剧情。

| 输入状态 | 预期行为 |
|---|---|
| 已有目标 Skill、BGM 和剧本 | 不再询问，脚手架记录 `scriptMode: user-provided`，按用户剧本制作 |
| 已有目标 Skill 和 BGM，未说明剧本 | 只询问一次“如果你有剧本的话，可以给我；没有的话，我就基于这个 Skill 自己思考并生成一版。” |
| 用户明确没有剧本或让 AI 决定 | 不再追问，记录 `scriptMode: agent-generated`，依据事实清单和故事语法构思 |
| 缺少目标 Skill 或 BGM | 只索取缺少的必需输入，不开始渲染 |
| 生成任意新动效 | 先应用内嵌 `motion-web` 的运动物理和验证规则，但保持 Codex 浅色视觉，不套用上游案例皮肤 |
