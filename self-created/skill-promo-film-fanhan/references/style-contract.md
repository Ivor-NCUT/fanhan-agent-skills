# Codex 浅色苹果式视觉与动效契约

## 固定视觉语言

- 画布默认 1080×1920、30fps，主体位于安全区内。
- 单一浅色 Codex 窗口贯穿全片：白色内容面、浅灰描边、浅蓝环境光、黑色正文、灰色辅助文字。
- 强调色只用克制的系统蓝；红色只用于通知红点或明确异常。
- 字体优先系统无衬线中文与 Inter；圆角、阴影和留白接近 macOS/Codex，不使用厚重玻璃拟态。
- 产品能力通过对话、文件、网页、执行日志和通知呈现，不通过抽象口号页或功能宫格呈现。

完整样式参考见 `../assets/reference-contact-sheet.png`。可运行实现参考见 `../assets/codex-light-template/`；其中业务文字仅为样例，不是必须保留的内容。

## 文字行为

- 用户输入：光标打字机，字符确定性出现；发送后形成浅灰气泡。
- AI 生成：字或短语逐个淡入，颜色从浅灰稳定到正文灰黑；不得模拟用户打字光标。
- 手机或窄画幅下中文不能单字成列；右侧面板太窄时先移动构图或依次展示左右区域。

## 连续转场

苹果式流畅感来自连续状态，不来自更长的淡入淡出：

1. 前一场景保留一个可追踪主体，例如 Codex 窗口、文件卡、输入框或中心卡片。
2. 转场前让主体轻微缩小并产生 2–5px 模糊；下一场景从相同位置、比例和模糊程度接管。
3. 下一状态快速启动、长减速回正，优先 `expo.out`、`circ.inOut` 或克制的 `power2`。
4. 不允许前后场景同时降到透明；背景亮度必须连续，避免白闪。
5. 除非表现真实碰撞，不使用明显回弹和弹簧过冲。

## 可组合镜头原型

- 输入框与对话：建立任务与 Agent 的判断。
- Skill/工具安装卡：只有真实流程包含安装时才使用。
- 文件逐行生长：表示沉淀、写入和可复用产物，可配笔尖或光标。
- 批量来源圆环：网页或内容卡沿圆柱排列，侧向转动后让选中卡回正；适合表达读取、比较与筛选。
- 左侧过程、右侧结果：右侧必须可读；空间不足时镜头先看左侧，再平移到右侧。
- 内容前后对比：只高亮真实变化，未修改部分保持稳定。
- 人类确认：Agent 准备完成后停在一个明确按钮，不虚构自动越权。
- 通知展开：右上角铃铛出现红点并配提示音，点击后从同一位置展开消息卡。
- 最终 Packshot：产物与一句结果文案稳定停留，不再快速堆动作。

每个镜头都必须承载故事状态变化；当前 Skill 不需要的原型不要使用。
