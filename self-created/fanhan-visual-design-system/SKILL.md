# 泛函视觉设计系统

把已定稿个人网站的视觉语言稳定地迁移到不同载体，同时保留内容清晰度、响应式与可编辑性。

## 使用方式

1. 先读 [视觉系统](references/visual-system.md)，确定颜色、字体、边框、阴影、间距、组件和禁用项。
2. 根据交付物只读 [载体配方](references/format-recipes.md) 中对应章节：网页、PPT/演示、3:4 卡片或长图海报。
3. HTML 产物优先复制并改造 [主题样式](assets/fanhan-theme.css) 与 [起始模板](assets/starter.html)，不要重新发明同义设计令牌。
4. 用户内容是事实来源；可整理层级和短句，但不得编造人物、数据、链接、案例或背书。
5. 交付真实可编辑产物，不只给设计建议。网页需验证桌面与窄屏；固定画布需按目标比例检查裁切、溢出和安全边距。

## 必须保持的识别特征

- 暖象牙白为主底，近黑文字，嫩绿色作强调；深色仅用于流程、机制或对比段落。
- 标题用宋体气质，正文用现代无衬线；靠字号、留白和块面建立层级，不靠装饰堆叠。
- 卡片使用清晰描边、克制圆角和少量右下硬阴影，按钮有轻微实体感。
- 信息密度适中，内容先于装饰；同组卡片、标题区和按钮需对齐且等高。
- 图标优先使用简洁线性 SVG，同一画面不重复图标，也不混用多套线宽。

## 边界与质量门槛

- 不引入霓虹紫蓝、炫光渐变、玻璃拟态、科技网格或泛 AI 机器人等模板化视觉。
- 不为了“像品牌”而把所有模块涂绿；绿色用于主行动、关键数字和选择状态。
- 正文与背景保持清晰对比；交互目标不小于 44px，并保留可见焦点。
- 动效只表达进入、归位、连接或流程，不妨碍阅读；同时支持 `prefers-reduced-motion`。
- 若目标平台的字体或效果不支持，优先保持信息层级与色彩关系，再使用载体配方中的降级方案。
