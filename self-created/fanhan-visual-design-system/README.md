# 泛函视觉设计系统

这是给泛函本人使用的品牌视觉 Skill。它把个人网站已经定稿的颜色、字体、边框、阴影、间距、卡片、按钮、响应式和动效规则，复用到网页、PPT、3:4 卡片与长图海报中。

## 最简单的使用方法

在 Codex 中输入：

```text
使用 $fanhan-visual-design-system，把以下内容设计成一张 3:4 卡片：……
```

也可以换成交付物类型：

```text
使用 $fanhan-visual-design-system，按泛函视觉设计系统制作一份 16:9 演示稿：……
```

```text
使用 $fanhan-visual-design-system，把这个网页改成泛函个人网站的视觉风格：……
```

## 你需要提供什么

提供真实内容、交付物类型和目标尺寸即可；有图片、链接、平台要求或必须保留的文字时一并发送。未指定尺寸时，Skill 会按对应载体的默认配方处理。

## 适用范围

- 网页与 HTML 原型
- PPT / 演示稿
- 3:4 卡片
- 长图海报
- 与上述结构相近的宣传物料

Skill 会保持暖象牙白、近黑文字、嫩绿色强调、宋体标题、清晰描边和克制硬阴影等识别特征，同时检查对齐、可读性、响应式和减少动效偏好。

给 Codex 的安装说明见 [CODEX_INSTALL.md](CODEX_INSTALL.md)。
