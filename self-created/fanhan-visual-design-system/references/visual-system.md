# 泛函视觉设计系统

基线：2026-09-05 定稿的 `Ivor-NCUT/fanhan-personal-website`。以下规则来自实际网页，不是通用“AI 科技风”推断。

## 1. 设计气质

关键词：温暖、可信、年轻、编辑感、轻复古、清晰、有一点实体触感。

视觉表达应像一本当代中文独立杂志与一个可靠人才网络的结合：大标题克制，卡片清楚，绿色提供生命力，黑色提供专业度。

## 2. 颜色

| 令牌 | 色值 | 用途 |
|---|---:|---|
| `paper` | `#FFFEF0` | 页面主背景、大面积留白 |
| `ink` | `#1B1B19` | 主文字、描边、深色段落 |
| `muted` | `#6F7068` | 次级说明、元数据 |
| `line` | `#D9D8CA` | 轻边框、分隔线 |
| `soft` | `#F3F2E4` | 次级卡片、弱区块 |
| `accent` | `#B8D98A` | 主按钮、重点卡片、关键标记 |
| `accent-strong` | `#527A34` | 焦点、连线、强调文字 |
| `dark-panel` | `#252522` | 深色模块内卡片 |
| `dark-copy` | `#AAA99D` | 深色背景上的次级文字 |

使用比例建议：`paper/soft` 约 70–85%，`ink` 约 10–20%，绿色约 5–12%。这是构图指导，不需要机械计算。

允许极轻的纸面光晕：`radial-gradient(circle, rgba(184,217,138,.20), transparent 35%)`。禁止把高饱和渐变当主背景。

## 3. 字体与层级

- 展示标题：`"STSong", "Songti SC", Georgia, serif`，常规或中等字重。
- 正文与控件：`"Avenir Next", "PingFang SC", "Microsoft YaHei", sans-serif`。
- 数字与短编号可沿用 Georgia 或正文无衬线，但同一组件保持一致。
- 大标题字距略收紧（`-0.03em` 至 `-0.065em`）；正文不要负字距。
- 正文行高 1.5–1.7；标题行高 1.02–1.18。

推荐层级：

- 网页主标题：`clamp(44px, 5vw, 72px)`。
- 网页模块标题：`clamp(36px, 4vw, 56px)`。
- 卡片标题：24–38px，按画布同比放大。
- 正文：14–18px；固定画布按照观看距离使用载体配方。

## 4. 间距与网格

- 基础间距单位：4px；常用步长为 8、12、16、24、32、48、72、108。
- 网页内容上限 1220px，左右安全边距桌面 20px 以上，手机 12px 以上。
- 相关元素靠近，不同信息组之间至少拉开一个间距层级。
- 同组卡片使用同一网格轨道并等高；标题换行不得破坏左右或上下对齐。
- 卡片内部通常使用 20–32px 内边距；手机端 16–22px。

## 5. 形状、描边与阴影

- 主圆角：18px；大容器 22–28px；小控件 8–14px。
- 常规卡片：1px `line`；重点卡片与按钮：2px `ink`。
- 实体阴影：`3px 3px 0 #1B1B19` 或 `5px 5px 0 #1B1B19`。
- 空间阴影只用于照片、浮层或粘性导航：`0 24px 80px rgba(50,44,28,.11)`。
- 不在同一组件同时使用强模糊阴影与强硬阴影。

## 6. 组件语法

### 按钮

绿色填充、2px 黑色描边、14px 圆角、硬阴影。悬停轻微向左上移动，按下向右下回落。次级按钮透明底且无硬阴影。

### 卡片

默认是纸白/柔米色底加细描边。重点卡片用 `accent`；过程卡片可用深色。卡片内容顺序为：元信息 → 标题 → 说明 → 标签或行动。

### 标签与编号

使用 1px 描边、8–9px 圆角、紧凑内边距。标签只辅助扫描，不承担完整句子。

### 品牌标记

圆形绿色底、2px 黑色描边，中间使用“函”字。它是识别锚点，不要在一个画面重复堆放。

### 图片

人物或实拍图使用自然光、低饱和、轻微对比增强；避免过度磨皮、强 HDR 和蓝紫色调。图片容器用 2px 黑边和 18px 圆角。

### 图标

使用 1.8–2px 线宽的单色 SVG，圆角端点，图标盒为方形圆角容器。每个语义使用独立图标。

## 7. 响应式

- 980px 以下减少三列密度；760px 以下重排为两列或单列；520px 以下进一步缩小留白和字号。
- 使用 `minmax(0, 1fr)`、`auto-fit`、`clamp()` 和 `aspect-ratio`，不要以固定绝对定位维持桌面构图。
- 手机端允许标题换行，但同组卡片需用拉伸或网格轨道保持底部齐平。
- 导航可在小屏隐藏次要链接，但必须保留品牌和主行动。

## 8. 动效

- 入场：透明度配合 14–32px 位移，时长 0.44–0.66s，缓动 `cubic-bezier(.16,1,.3,1)`。
- 组合对象按 50–100ms 依次归位；连接线可用慢速流动效果。
- 悬停位移不超过 3px。
- 在 `prefers-reduced-motion: reduce` 下关闭非必要动画。

## 9. 禁用项

- 蓝紫霓虹、发光描边、深空背景、代码雨、六边形科技网格。
- 大面积玻璃拟态和不可读的透明叠层。
- 多套圆角、多套阴影、多套图标风格混杂。
- 过度居中所有正文、无层级的大段文本、装饰性英文口号堆叠。
- 为填满空间而添加不存在的数据、合作方或能力。
