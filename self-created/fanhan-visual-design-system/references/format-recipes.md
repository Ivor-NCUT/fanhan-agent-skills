# 载体配方

先遵循视觉系统，再使用对应配方。内容量超出时优先拆页或加长画布，不缩到难读。

## 网页与 HTML 原型

- 画布：流式宽度，内容上限 1220px；主视觉尽量占据首屏但不裁切核心内容。
- 结构：品牌与主行动 → 一句话主张 → 核心关系/价值 → 深色流程或机制 → 资源/案例 → 行动卡片。
- 网格：桌面 3 列或“侧栏—中心—侧栏”；平板 2 列；手机单列或结构明确的 2 列。
- 复用 `assets/fanhan-theme.css`，从 `assets/starter.html` 开始替换内容。
- 验证至少一个约 1280px 桌面视口和一个约 390px 手机视口；检查横向溢出、等高、标题换行、44px 点击区和可见焦点。

## PPT / 演示

- 默认 16:9；若用户指定比例，以指定比例为准。
- 安全边距：画布宽高的 5–7%。
- 一页一个结论：上方眉题或编号，中部大标题，下方用 1–3 个卡片承接证据。
- 标题约 42–64pt，正文 20–28pt，注释不低于 14pt。
- 封面与章节页用 `paper` 大留白；流程页可切换为 `ink` 深色底；结论页用单张绿色重点卡片。
- 宋体不可用时用平台可用的中文宋体；正文优先苹方、微软雅黑或相近的人文无衬线。
- 不把网页导航、悬停状态或滚动逻辑生搬到幻灯片。

## 3:4 卡片

- 推荐 1080×1440；安全边距 72px。
- 最多三层：眉题/品牌、主结论、证据或行动。
- 主标题 64–88px，正文 30–40px，标签/元信息 22–28px。
- 使用一个主视觉锚点：人物、数字、引用或重点卡片，四选一。
- 行动按钮放底部并与正文保持至少 48px 间距；不把多个同级按钮挤在一排。
- 可直接把 `starter.html` 的画布类设为 `fh-card-3x4`。

## 长图海报

- 推荐宽 1080px，高度随内容增长；安全边距 72px，模块间距 72–120px。
- 首屏说明“是什么/给谁/为什么现在看”；中段按问题—方法—证据组织；末尾只留一个主行动。
- 用纸白段落做阅读主体，每 2–4 个浅色模块最多插入一个深色流程段或绿色结论段。
- 重复卡片必须同宽、同内边距、同标题基线。信息过多时增加画布高度，不减少安全边距。
- 二维码周围保留足够空白，不叠加纹理、阴影或装饰线。

## 其他宣传物料

选择结构最接近的配方：信息流封面靠近 3:4 卡片，横版活动屏靠近 PPT，落地页靠近网页，详情长图靠近长图海报。只迁移视觉语法，不机械复制尺寸。

## 导出检查

- 字体未替换、没有溢出或意外断行。
- 绿色仍是强调而非背景噪音。
- 同组元素对齐，边框粗细统一，硬阴影方向统一为右下。
- 关键文字与二维码在安全区内。
- 输出尺寸、比例、色彩模式和文件格式符合目标平台。
