# 方比比视频号标题方法论

## Purpose

把一段方比比视频号文案，转成能让目标受众点开并看完的两行标题。

这个 skill 不是普通摘要标题。它服务于一个非常具体的内容模型：

- 核心人设：年入百万的00后。
- 核心受众：50岁以上、二三线城市或小镇女性，尤其是妈妈、父母、长辈视角。
- 核心情绪：意外、揪心、骄傲、被理解、被孩子看见、对孩子未来的希望。
- 标题目标：开环，不提前讲答案；把文案里最有情绪张力的过程写成钩子。

原始方法论和案例库在 `references/source-methodology.md`。需要深挖具体案例时再读取，不要每次都把全文搬进回答。

## When Input Is Incomplete

如果用户没有提供文案、片段、选题或标题方向，只问一个问题：

> 这条视频的原文案或核心故事是什么？

如果用户给了文案但看不出目标受众是否仍是方比比视频号默认人群，先按默认人群处理，不额外追问。

## Core Rules

标题必须符合这个固定结构：

```text
年入百万00后
[10字以内钩子]
```

第二行只写一个短钩子，优先包含“妈妈”“孩子”“父母”之一。能自然出现“妈妈”时优先用“妈妈”，因为它最贴近受众身份。

标题要开环：写出反常动作、情绪冲突或未解释的真相，不要在标题里说出视频结论、方法答案或最终价值观。

标题要让人想知道“为什么会这样”。不要把标题写成观点总结、金句、课程标题或公众号标题。

避免激发强负面情绪。可以有委屈、心疼、轻微冲突和悬念，但不要制造恐惧、绝望、羞辱、威胁或家庭撕裂感。最终气质要落在爱、希望、被看见、正能量或纯悬念上。

## Title Logic Library

优先从文案中寻找这些爆点：

- 身份反转：成功者承认自己没做好、被父母保护、反过来照顾妈妈。
- 母亲高光：妈妈做了一个具体动作，让孩子一生记得。
- 家庭真相：孩子不尊重妈妈、孩子不结婚、孩子不敢说钱，背后另有原因。
- 财富回馈：赚到钱后怎么对父母、给多少钱、买什么礼物、怎么表达想家。
- 低门槛捷径：妈妈只做了一件事、母亲只教了一句话，却影响孩子结果。
- 代际认知差：孩子瞒着、不敢说、被父母发现、父母听不懂但默默支持。
- 传统信念：招财、面相、修心、低调、节俭、家风、厚积薄发。
- 命运预测：这种孩子注定挣大钱、大老板扶持这种人、男生女生谁更赚钱。

常用钩子词只作为方向，不要机械套用：

- 动作类：瞒着、不敢说、揭穿、偷偷、挡在、劝我、只教。
- 关系类：妈妈、父母、孩子、老家、丈母娘。
- 反差类：真相、反而、竟然、原来、却、唯一。
- 价值类：最贵、招财、挣大钱、害怕、心愿。

## Working Procedure

1. 先读文案，标出最强的“标题核心依据”。优先选择一句原文或一个具体动作，而不是抽象主题。
2. 判断这个点为什么会击中 50 岁妈妈：意外、揪心、委屈、骄傲、被孩子理解，还是对孩子前途有希望。
3. 把最终结论藏起来，只保留过程冲突、反常行为或情绪开口。
4. 生成 5 个标题，每个标题都用两行结构。
5. 给出简短判断：最推荐哪一个，以及它使用了什么逻辑。

## Quality Checklist

交付前检查：

- 第一行是否固定为“年入百万00后”。
- 第二行是否不超过 10 个汉字；如果略超，必须有明显更强的传播理由。
- 第二行是否包含“妈妈”“孩子”“父母”之一，除非文案确实更适合“丈母娘”“老家”等关系词。
- 标题是否保留悬念，没有提前泄露答案。
- 标题是否来自文案真实内容，没有凭空编造剧情。
- 标题是否更像视频号封面标题，而不是文章标题。
- 情绪是否有张力但不过度负面。

## Bad Patterns

避免这些写法：

- “年入百万00后 / 学会夸奖很重要”：这是结论，不是钩子。
- “年入百万00后 / 妈妈很伟大”：太泛，没有过程悬念。
- “年入百万00后 / 家庭教育方法”：太像课程标题。
- “年入百万00后 / 父母毁了孩子”：负面过重，容易伤害账号气质。
- “年入百万00后 / 我妈让我成功”：提前闭环，缺少点开理由。
