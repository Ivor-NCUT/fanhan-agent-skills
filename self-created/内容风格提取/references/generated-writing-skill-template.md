# [账号名]公众号风格写作

## 使用方式

当任务匹配该 skill 时，先判断用户要做什么：

- 诊断：用户提供已有稿件，想知道和目标风格差在哪里。
- 润色：用户提供已有稿件，想改成目标风格。
- 从素材创作：用户提供主题、素材、访谈、提纲或观点，想写成完整公众号文章。
- 局部优化：用户只要标题、开头、结尾或某一节。

如果缺少关键信息，最多问一个问题。能基于现有素材先产出版本时，先产出可审查版本。

## 工作流

### 诊断

1. 判断稿件属于哪类内容。
2. 对照目标风格，从选题、结构、语言、论证、读者关系、事实密度六个维度诊断。
3. 给出 3-5 个最重要问题。
4. 每个问题给一个具体修改方向，必要时给短 before/after。

### 润色

1. 保留用户原有事实、观点、案例和边界。
2. 调整结构，让文章更接近目标公众号的展开方式。
3. 调整语言节奏，但不要只替换口头禅。
4. 输出完整改写稿。
5. 附上「主要改动说明」。

### 从素材创作

1. 先识别素材中最有价值的核心观点或故事。
2. 选择适合目标公众号的文章类型和结构。
3. 先写标题和开头，再展开正文。
4. 缺事实时标注待补，不编造。
5. 输出完整文章。

### 局部优化

按用户指定部件输出 3-5 个候选，并说明每个候选适合的读者感受或传播场景。

## 边界

- 不编造作者经历、客户案例、数据和公众号历史。
- 不洗稿；如果用户给的是竞品文章，提炼结构和方法后，用用户自己的素材重写。
- 不把风格简化成口癖或固定句式。
- 用户事实优先，风格规则其次。

## 自检清单

交付前检查：

- 是否符合目标账号的作者站位和读者关系。
- 是否复刻了结构和思维方式，而不只是语气。
- 是否保留了用户提供的事实。
- 是否有足够具体的场景、案例、动作或判断。
- 是否删掉了空泛套话和无依据判断。
