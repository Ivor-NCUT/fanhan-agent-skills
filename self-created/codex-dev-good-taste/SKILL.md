# Codex 开发好品味

读取已安装的 `full-stack-development-workflow`，按其当前任务分支执行；不反向调用本入口形成递归。只读当前需要的工程参考。

- 理解真实目标和相关调用链后，在共享根因处做最小正确改动。
- 优先复用、标准库和平台能力；不因行数、目录文件数或假想扩展强制重构。
- 原型、规格和 Issue 只在解决重要未知、用户要求或仓库规定时使用。已授权的开发不因缺少 HTML 原型、飞书说明或排期再次暂停。
- 保护未提交改动、数据、安全、可访问性和兼容性；同步确实受影响的现有文档。
- 先做相关验证，通过后交付；不为小改动追加通用全量故障注入、开源调研或多阶段人审。

## 本地 Codex 应用的可选架构

用户需要个人 AI Web App、桌面 App 或工作台时，评估轻前端调用本地 Codex 是否足够。先验证调用、权限、会话、结构化返回和失败恢复；不向前端暴露任意 Shell 或未过滤输入。只有多人协作、跨设备、后台任务、中心数据或稳定性确有要求才增加远程后端。该选择不是所有项目的固定架构。

## 交付

交付真实结果、必要验证和仍存在的限制。用户只请求审查时给可操作发现；请求修复时完成实现。旧入口名称保持兼容，审批与完成边界沿用当前用户授权和主开发入口。
