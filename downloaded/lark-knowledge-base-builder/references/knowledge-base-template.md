# 飞书知识库结构模板

## 1. 总目录文档

标题：`00 知识库总目录`

```markdown
# 00 知识库总目录

本知识库用于：[知识库主题]，服务于 [人类读者] 和 [AI Agent 查询场景]。

## Agent 查询路线

1. 根据问题关键词和意图，先在“子目录索引”中选择最可能的目录。
2. 进入子目录后，先读取 `00 目录指引`。
3. 根据指引里的文档索引选择 1-3 篇候选文档。
4. 读取候选文档第一块摘要。
5. 只有摘要明确匹配时，继续读取正文。

## 子目录索引

| 子目录 | 主要内容 | 适合查询的问题 | 不适合查询的问题 |
| --- | --- | --- | --- |
| [子目录 A] | [内容范围] | [典型问题] | [边界] |
| [子目录 B] | [内容范围] | [典型问题] | [边界] |

## 维护规则

- 新增子目录：同步更新本总目录的子目录索引。
- 新增正文文档：同步更新所属子目录的 `00 目录指引`。
- 正文文档：第一块必须是摘要，说明内容范围、适合问题和查询边界。
```

## 2. 子目录指引文档

标题：`00 目录指引`

```markdown
# 00 目录指引

本目录用于：[问题域/业务域]。

## 适合查询

- [问题类型 1]
- [问题类型 2]
- [问题类型 3]

## 不适合查询

- [容易误入的问题 1]：应改查 [目录/文档]。
- [容易误入的问题 2]：应改查 [目录/文档]。

## 文档索引

| 文档 | 记录内容 | 适合回答的问题 | 阅读建议 |
| --- | --- | --- | --- |
| [正文文档 A] | [内容摘要] | [问题类型] | 先读首块摘要，匹配后再阅读全文 |
| [正文文档 B] | [内容摘要] | [问题类型] | 只需读取指定章节/表格 |
```

## 3. 正文文档首块摘要

把下面这段放在正文第一块，正文内容从第二块开始。

```markdown
> 本文摘要：本文记录 [主题/对象] 的 [核心知识类型]，主要用于回答 [问题 A、问题 B、问题 C]。如果你要找 [不属于本文的问题]，应返回上级目录改查 [更合适的目录/文档]。
```

## 4. 搭建结果汇报

```markdown
已按“总目录 -> 子目录指引 -> 正文首块摘要”的结构完成知识库设计。

- 知识库总目录：[标题或链接]
- 子目录：
  - [目录 A]：[一句话说明]
  - [目录 B]：[一句话说明]
- Agent 查询路径：先读总目录，再读对应目录指引，最后用正文首块摘要判断是否读取全文。
- 还需补充：[缺失资料/待确认落点/待迁移文档]
```
